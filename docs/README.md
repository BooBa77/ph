# Документация PeakHunter

Короткий индекс. Всё здесь — про проект целиком и обновляется по ходу работ.

| Документ | О чём |
|---|---|
| [stack.md](stack.md) | Технологический стек: какие библиотеки и модули используются и зачем |
| [INFRASTRUCTURE.md](INFRASTRUCTURE.md) | Сервер, прод-стек, маршрутизация, доступы, секреты, деплой, грабли |

**Чего здесь намеренно нет.** Журналы работ (что делали в такую-то дату, что
нашли, на чём споткнулись) лежат в `backups/` — эта папка в `.gitignore` и
остаётся локальной. Документация описывает **текущее устройство**, журнал —
**историю**.

Правило для правок: если документ разошёлся с кодом, прав источник — код,
а документ нужно догнать.
